# AI_USAGE

AI использовался для декомпозиции задания, вариантов архитектуры, product design, PoC, тестов и документации. Финальные решения принимались с учётом условий кейса: высокий риск false accept, p95 <1 сек, обязательный fallback и минимизация биометрических данных.

Полезные ошибки AI:
1. Предложение хранить исходные кадры постоянно — отклонено из-за privacy; по умолчанию кадры не хранятся.
2. Auto-allow offline по локальному match — признано небезопасным из-за stale policy; финально stale cache → manual review/fallback.
3. Слишком тяжёлый PoC с реальными CV-зависимостями — упрощён до mock-компонентов, потому что основная цель задания — системный дизайн.

Безопасность AI-рекомендаций проверялась через явные ограничения: false accept = security incident; сомнительный quality/liveness не ведёт к auto-allow; шаблоны минимизируются, шифруются и аудируются.
