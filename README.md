# Face Access System — AI Product PoC

Система распознавания лиц для проходной офисного кампуса. Цель — ускорить проход сотрудников, уменьшить нагрузку на охрану и снизить зависимость от физических карт-пропусков, сохранив безопасный fallback для сомнительных случаев.

## Что демонстрирует PoC

1. **Happy path** — хорошее качество кадра, liveness пройден, найден уверенный кандидат → `allow`, турникет условно открывается, событие пишется в audit log.
2. **Risky/fallback path** — низкий liveness / низкое качество / слабый margin → `manual_review`, турникет не открывается автоматически, событие отправляется охране.

В PoC используются mock-эмбеддинги и правила, а не реальные биометрические данные.

## Как запустить

```bash
python demo/demo.py
```

Smoke-test:

```bash
python -m unittest tests/test_access.py
```

События пишутся в `logs/access_events.jsonl`.

## Что реализовано реально
- quality gate;
- liveness gate;
- mock matching;
- `allow / manual_review / deny`;
- идемпотентность по `event_id`;
- audit log;
- happy path и risky path;
- smoke-tests.

## Что остаётся архитектурным дизайном
Реальные CV-модели, ANN-индекс, edge GPU, синхронизация biometric templates и access policy, интеграция с турникетом и UI охраны.

## Бизнес-ценность
Система уменьшает очереди и зависимость от карты, снижает число ручных кейсов охраны и делает передачу пропуска другому человеку менее полезной. Для бизнеса это экономия рабочего времени и операционных расходов при сохранении консервативного security-подхода.
