# Face Access System — AI Product PoC

Система распознавания лиц для проходной офисного кампуса. Цель — ускорить проход сотрудников, снизить нагрузку на охрану и уменьшить зависимость от физических карт-пропусков, сохранив безопасный fallback для сомнительных случаев.

## Что демонстрирует PoC

PoC показывает два end-to-end сценария:

1. **Happy path** — хорошее качество кадра, liveness пройден, mock-эмбеддинг уверенно совпал с сотрудником → `allow`, турникет условно открывается, событие пишется в audit log.
2. **Risky/fallback path** — подозрительный liveness → `manual_review`, турникет остаётся закрытым, причина решения фиксируется в логе.

Дополнительно есть smoke-tests и проверка идемпотентности по `event_id`.

## Как запустить

Требуется Python 3.10+.

```bash
python demo/demo.py
```

Тесты:

```bash
python -m unittest tests/test_access.py
```

После запуска события пишутся в:

```text
logs/access_events.jsonl
```

## Что реализовано реально

- обработка mock-события;
- quality gate;
- liveness gate;
- mock face embeddings;
- one-to-many matching по cosine similarity;
- пороги `allow / manual_review / deny`;
- идемпотентность по `event_id`;
- audit log;
- happy path и risky path;
- smoke-tests.

## Что является архитектурным дизайном

- реальные CV-модели детекции, alignment, liveness и face embedding;
- ANN-индекс для сотен тысяч лиц;
- edge-инференс на GPU;
- синхронизация biometric templates и access policy;
- интеграция с турникетом;
- интерфейс охраны;
- мониторинг и централизованный audit trail.

## Допущения

- основной inference выполняется на edge;
- центральный сервис управляет enrollment, шаблонами, политиками доступа и аудитом;
- исходные изображения по умолчанию не сохраняются;
- edge хранит шифрованный кеш эмбеддингов и policy с ограниченным TTL;
- при сомнении система не открывает турникет автоматически;
- false accept существенно дороже false reject.

## Ограничения MVP

- нет реальных камер;
- нет production liveness-модели;
- нет реальных биометрических данных;
- ANN заменён простым перебором маленькой mock-базы;
- нет production-интеграции с турникетом;
- offline-кеш и синхронизация смоделированы правилами.

## Бизнес-ценность

Для сотрудника система сокращает время прохода и зависимость от карты. Для охраны она убирает часть типовых ручных кейсов и оставляет человеку только сомнительные события. Для бизнеса это экономия рабочего времени, снижение операционных затрат и более устойчивый контроль доступа. Ключевой принцип решения — ускорять проход только там, где это не ухудшает безопасность.
